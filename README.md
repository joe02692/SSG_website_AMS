# ⚜️ El-Salam Scouting Group | Web Portal & AMS

An integrated Web Portal and Association Management System (AMS) custom-built for the El-Salam Scouting Group. 

This project serves two primary functions:
1. **Public Portfolio:** A modern, high-performance landing page acting as a "digital business card" to showcase our history, camp galleries, and upcoming events to parents and new scouts.
2. **Internal Management System (AMS):** A secure, authenticated dashboard for troop leaders to manage over 400 scout profiles, track attendance, and digitize administrative records, replacing outdated spreadsheet workflows.

### 💻 Tech Stack
* **Frontend & Backend:** Next.js
* **Database & Authentication:** Supabase (PostgreSQL)
* **Media & Image Storage:** Cloudinary
* **Hosting & Deployment:** Vercel
